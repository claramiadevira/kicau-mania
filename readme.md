# 🐦 Kicau Mania

A simple bird sound recognition game built with Python.

## Features

- Play bird sounds
- Guess the correct bird
- Simple and fun gameplay
- Built as a learning project

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python kicau.py
```
